# Kora

Kora is a mini programming language built from scratch in Go. It helps developers understand how languages turn raw source code into meaningful tokens, making it a great learning resource for anyone curious about compilers, interpreters, and language design.

## Description

Kora takes source code and breaks it down into a clean stream of tokens. It recognizes keywords, identifiers, numbers, strings, operators, delimiters, and newlines while tracking exact line and column positions. If you have ever wanted to build your own programming language, Kora gives you a solid starting point with a working lexer you can run and extend.

## Installation

- Clone the repository:

```bash
git clone git@github.com:HassanAmirii/kora.git
```

- Change into the project directory:

```bash
cd kora
```

- Make sure Go is installed on your machine. You can check with:

```bash
go version
```

- Run the project:

```bash
go run ./cmd/kora
```

## Usage

Kora ships with a small built-in example in `cmd/kora/main.go`. When you run it, the lexer scans the sample code and prints each token it finds.

Try editing the source string in `cmd/kora/main.go`:

```go
source := `set age >= 21
set name = "kenny"`
```

Then run:

```bash
go run ./cmd/kora
```

You will see output showing each token type, lexeme, line, and column.

```text
Type: KEYWORD | Lexeme: "set" | Line: 1, Column: 1 
Type: IDENTIFIER | Lexeme: "age" | Line: 1, Column: 5 
Type: OPERATOR | Lexeme: ">=" | Line: 1, Column: 9 
Type: NUMBER | Lexeme: "21" | Line: 1, Column: 12 
Type: NEWLINE | Lexeme: "\n" | Line: 1, Column: 14 
Type: KEYWORD | Lexeme: "set" | Line: 2, Column: 1 
Type: IDENTIFIER | Lexeme: "name" | Line: 2, Column: 5 
Type: OPERATOR | Lexeme: "=" | Line: 2, Column: 10 
Type: STRING | Lexeme: "kenny" | Line: 2, Column: 12 
```

## Features

- **Tokenizes source code** into keywords, identifiers, numbers, strings, operators, delimiters, and newlines.
- **Tracks position info** with line and column numbers for every token.
- **Supports two-character operators** like `>=`, `<=`, `==`, `!=`, `&&`, `||`, `++`, `--`, `+=`, and `-=`.
- **Handles string literals** enclosed in double quotes.
- **Reports errors** for unexpected characters and unterminated strings.
- **Simple Go codebase** that is easy to read, extend, and integrate into larger projects.
